# AKB48 Mail Backup Tool

AKB48 Mailのメール本文・画像をPCへ保存するための、非公式バックアップツールです。

本ツールは、iPhoneで利用しているAKB48 Mailの通信情報をもとに、
自分のアカウントで正規に受信・閲覧できるメールを保存する用途を想定しています。

作者環境では、メール本文・画像の全件保存まで確認済みです。

## 対応環境

現在、以下の環境で動作確認しています。

- iPhone
- Windows PC
- Python 3

スマートフォンの通信内容を確認するために、CharlesなどのHTTP通信解析ツールが別途必要です。

Charles以外でも、Request Headersを確認できるツールであれば利用できる可能性があります。

## 内容

配布ファイルには、大きく分けて2つのツールが入っています。

### STEP1：メール一覧取得

AKB48 Mailの受信一覧APIからメール情報を取得し、STEP2で使用するCSVを作成します。

主な出力ファイル：

- `STEP2入力用_全メール一覧.csv`
- `全MailID一覧.txt`
- メンバー別確認用CSV / TXT
- `STEP1取得結果.txt`

通常は、STEP1で作成された

`STEP2入力用_全メール一覧.csv`

をSTEP2で使用します。

### STEP2：本文・画像バックアップ

STEP1で作成したCSVを読み込み、各メールの本文と画像を保存します。

保存先は実行時に自由に選択できます。

保存先には、

`AKBメールバックアップ`

フォルダが作成され、その中にメンバー別で本文・画像が保存されます。

例：

```text
AKBメールバックアップ
├─ メンバー名_ID
│  ├─ 本文
│  │  ├─ 日時_mailID.txt
│  │  └─ ...
│  └─ 画像
│     ├─ mailID_01.jpg
│     ├─ mailID_02.jpg
│     └─ ...
└─ バックアップ結果.txt
基本的な使い方
1. Pythonをインストール
Python 3をWindows PCへインストールしてください。
Pythonについて詳しく理解している必要はありません。
2. スマートフォンの通信を確認
CharlesなどのHTTP通信解析ツールを使用し、
AKB48 Mailアプリの通信内容を確認します。
STEP1では、受信一覧を開いたときの /v1/inbox のRequest Headersを使用します。
STEP2では、実際にメール本文を開いたときの /mail/mxxxxx のRequest Headersを使用します。
3. STEP1を実行
STEP1の .bat ファイルを起動します。
通常は最初から入力されているURLを変更する必要はありません。
Request Headersを貼り付け、取得ページ数を指定して実行してください。
最初は1ページだけ取得して、正常に動作するか確認することをおすすめします。
全件取得する場合は、画面の案内に従って最後まで取得してください。
4. STEP2を実行
STEP2の .bat ファイルを起動します。
STEP1で作成した
STEP2入力用_全メール一覧.csv
を選択します。
次に、メール詳細ページのRequest Headersを貼り付けます。
保存するメール数、通信間隔、画像保存の有無などを設定して実行してください。
処理メール数を 0 にすると全件を対象にできます。
通信間隔について
STEP2では、ネットワークへのリクエストごとに一定の間隔を空けます。
初期値は0.5秒です。
例：
本文取得
↓
0.5秒以上
↓
画像1枚目
↓
0.5秒以上
↓
画像2枚目
↓
0.5秒以上
↓
次のメール
大量のメールや画像を保存する場合は、処理に時間がかかります。
作業中はPCがスリープしないよう、あらかじめWindowsの電源設定を確認してください。
画面の前に張り付いている必要はありません。
処理が正常に開始されたことを確認したら、そのまま待つことができます。
ノートPCの場合は、電源へ接続した状態での実行をおすすめします。
途中再開について
STEP2には、保存済みメールをスキップする機能があります。
途中で処理が止まった場合でも、同じCSVと同じ保存先を指定して再実行することで、保存済みのデータを飛ばしながら再開できます。
Request Headersについて
Request Headersには、以下のような情報が含まれる場合があります。
- User-Id
- Access-Token
- Application-Version
- Device-Version
- Os-Version
- User-Agent
本ツールでは、公式アプリが実際に送信しているRequest Headersをまとめて貼り付ける方式を採用しています。
一部の不要なヘッダーはツール側で自動的に除外します。
特に、
If-None-Match
はキャッシュに関係するため、自動的に除外するようにしています。
認証情報について
User-Id、Access-Token、Request Headersなどには認証に関係する情報が含まれます。
これらをSNS、ブログ、GitHub、掲示板などへ公開しないでください。
通信解析ソフトのスクリーンショットを共有する場合も、認証情報が写っていないか必ず確認してください。
本ツールは、入力されたRequest HeadersやAccess-Tokenを結果ファイルへ保存しない設計になっています。
AIを使った操作補助
使い方が分からない場合は、ChatGPT、Geminiなどの生成AIへ、このGitHubリポジトリや解説記事のURLを渡して操作を案内してもらう方法をおすすめします。
分からない画面やエラーが表示された場合は、スクリーンショットをAIへ見せると状況を確認しやすくなります。
必要であれば、STEP1 / STEP2のPythonファイルそのものをAIに読ませて質問することもできます。
