# AKB48 Mail Backup Tool

AKB48 Mailのメール本文・画像をPCへ保存するための、非公式バックアップツールです。

本ツールは、iPhoneで利用しているAKB48 Mailの通信情報をもとに、
自分のアカウントで正規に受信・閲覧できるメールを保存する用途を想定しています。

作者環境では、メール本文・画像の全件保存まで確認済みです。

## 対応環境

現在、以下の環境で動作確認しています。

- iPhone
- Windows PC
- Python 3

スマートフォンの通信内容を確認するために、CharlesなどのHTTP通信解析ツールが別途必要です。

Charles以外でも、Request Headersを確認できるツールであれば利用できる可能性があります。

## 内容

配布ファイルには、大きく分けて2つのツールが入っています。

### STEP1：メール一覧取得

AKB48 Mailの受信一覧APIからメール情報を取得し、STEP2で使用するCSVを作成します。

主な出力ファイル：

- `STEP2入力用_全メール一覧.csv`
- `全MailID一覧.txt`
- メンバー別確認用CSV / TXT
- `STEP1取得結果.txt`

通常は、STEP1で作成された

`STEP2入力用_全メール一覧.csv`

をSTEP2で使用します。

### STEP2：本文・画像バックアップ

STEP1で作成したCSVを読み込み、各メールの本文と画像を保存します。

保存先は実行時に自由に選択できます。

保存先には、

`AKBメールバックアップ`

フォルダが作成され、その中にメンバー別で本文・画像が保存されます。

例：

```text
AKBメールバックアップ
├─ メンバー名_ID
│  ├─ 本文
│  │  ├─ 日時_mailID.txt
│  │  └─ ...
│  └─ 画像
│     ├─ mailID_01.jpg
│     ├─ mailID_02.jpg
│     └─ ...
└─ バックアップ結果.txt
